===================
OpenSearch에 요청
===================

개요
====

이 페이지에서는 JSON 파일에 작성한 요청을 OpenSearch에 전송합니다.

|image0|

이 화면은 왼쪽 메뉴에 없습니다. 표시하려면 관리자로 로그인한 후 ``/admin/sereq/`` 를 URL 경로로 입력하십시오.
요청을 전송하려면 ``admin`` 역할(관리자) 또는 ``admin-sereq`` 역할이 필요합니다.

작업 방법
=========

요청 전송
---------

OpenSearch에 전송하려는 요청을 JSON 파일로 작성하여 "요청 파일"로 해당 파일을 선택하고 "전송" 버튼을 클릭하면 OpenSearch에 요청이 전송됩니다.
응답은 파일로 다운로드됩니다.

설정 항목
---------

요청 파일
:::::::::

요청을 기술한 파일을 지정합니다.

첫 번째 줄에 ``<메서드> <경로>`` 를 공백 하나로 구분하여 작성하고, 두 번째 줄부터 요청 본문(쿼리 DSL 등)을 작성합니다.
메서드로는 GET, POST, PUT, DELETE를 사용할 수 있습니다. 경로는 OpenSearch에 대한 경로이며 맨 앞의 ``/`` 는 생략할 수 있습니다.
예를 들어, 파일의 내용은 다음과 같습니다.

::

    POST /_search
    {
      "query": {
        "match_all": {}
      }
    }

본문의 줄바꿈은 제거되고 각 줄이 연결되어 전송됩니다. 따라서 한 줄에 JSON 하나를 나열하는 형식(``_bulk`` 등)의 요청은 전송할 수 없습니다.

.. warning::

   메서드가 PUT이나 DELETE인 요청도 그대로 OpenSearch에 전송됩니다.
   파일의 내용에 따라서는 |Fess| 가 사용하는 인덱스를 변경하거나 삭제하여 데이터를 잃게 될 수 있습니다. 전송하기 전에 내용을 충분히 확인하십시오.
