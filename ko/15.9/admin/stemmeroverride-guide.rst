===============
Stemmer 재정의 사전
===============

개요
====

특정 단어의 어간(stem)을 지정한 어간으로 재정의할 수 있습니다. 스테밍 처리 결과가 의도와 다른 단어에 사용합니다.
예를 들어 ``mice`` 의 어간을 ``mous`` 로 지정하면 ``mice`` 와 ``mouse`` 를 같은 단어로 검색할 수 있습니다(영어 스테머는 ``mouse`` 를 ``mous`` 로 만듭니다).

기호·문자 코드·전각반각 등의 문자를 다른 문자로 치환하는 것은 이 사전의 기능이 아닙니다. 문자 치환 사전( :doc:`mapping-guide` )을 사용하십시오.

목록에는 언어별 사전(``en/stemmer_override.txt`` 등)이 표시됩니다. 등록할 단어의 언어에 맞는 사전을 선택하여 편집하십시오. 어떤 사전이 어떤 필드에 적용되는지는 :doc:`dict-guide` 를 참조하십시오.
저장하는 것만으로는 검색에 반영되지 않습니다. 반영하는 절차는 :ref:`dict-apply-changes` 를 참조하십시오.

관리 방법
======

표시 방법
------

아래 그림의 Stemmer 재정의 설정 목록 페이지를 열려면 왼쪽 메뉴의 [시스템 > 사전]을 선택한 후 stemmeroverride를 클릭합니다.

|image0|

편집하려면 설정 이름을 클릭합니다.

설정 방법
------

Stemmer 재정의 설정 페이지를 열려면 신규 생성 버튼을 클릭합니다.

|image1|

설정 항목
------

변환원
:::::

어간을 재정의하려는 단어를 입력합니다. 분석은 단어를 소문자로 바꾼 뒤 대조하므로 소문자로 입력하십시오.

변환후
:::::

변환원에 입력한 단어의 어간으로 사용할 단어를 입력합니다.
변환 후 단어는 스테밍되지 않고 그대로 인덱싱됩니다. 검색어는 스테밍되므로 원래 단어와 같은 검색 결과를 얻으려면 일반 단어를 스테머에 통과시킨 결과(``mouse`` 의 경우 ``mous``)를 지정합니다.
예를 들어 변환원에 ``mice``, 변환후에 ``mous`` 를 입력합니다.

다운로드
=========

Stemmer 재정의 사전 형식으로 다운로드할 수 있습니다.

업로드
=========

Stemmer 재정의 사전 형식으로 업로드할 수 있습니다.

.. warning::

   업로드하면 사전의 내용이 업로드한 파일의 내용으로 교체됩니다. 화면에서 등록한 항목을 포함하여 파일에 없는 것은 삭제됩니다. 필요한 경우 먼저 다운로드하여 사본을 보관하고, 그 내용을 포함하여 업로드하십시오.
