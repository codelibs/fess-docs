============
Protwords 사전
============

개요
====

스테밍 처리 대상에서 제외할 단어를 관리할 수 있습니다.
스테밍 처리는 기본적으로 규칙 기반 처리이므로 의도하지 않은 정규화가 수행될 가능성이 있습니다.
예를 들어 Maine(미국 주 이름)이라는 단어는 main으로 정규화됩니다.

이 단어를 그대로 검색할 수 있게 하려면 ``maine`` 을 등록합니다(단어는 소문자로 작성합니다. 자세한 내용은 "설정 항목"을 참조하십시오).

목록에는 언어별 사전(``en/protwords.txt``, ``de/protwords.txt`` 등)이 표시됩니다. 등록할 단어의 언어에 맞는 사전을 선택하여 편집하십시오. 어떤 사전이 어떤 필드에 적용되는지는 :doc:`dict-guide` 를 참조하십시오.
저장하는 것만으로는 검색에 반영되지 않습니다. 반영하는 절차는 :ref:`dict-apply-changes` 를 참조하십시오.

관리 방법
======

표시 방법
------

아래 그림의 Protwords 설정 목록 페이지를 열려면 왼쪽 메뉴의 [시스템 > 사전]을 선택한 후 protwords를 클릭합니다.

|image0|

편집하려면 설정 이름을 클릭합니다.

설정 방법
------

Protwords 설정 페이지를 열려면 신규 생성 버튼을 클릭합니다.

|image1|

설정 항목
------

단어 정보
::::::

스테밍 처리 대상에서 제외할 단어를 입력합니다.

단어는 소문자로 입력하십시오. 분석은 단어를 소문자로 바꾼 뒤 이 사전과 대조하므로 ``Maine`` 을 입력해도 보호되지 않습니다. 개요의 예에서는 ``maine`` 을 입력합니다.


다운로드
=========

Protwords 사전 형식으로 다운로드할 수 있습니다.

업로드
=========

Protwords 사전 형식으로 업로드할 수 있습니다.

.. warning::

   업로드하면 사전의 내용이 업로드한 파일의 내용으로 교체됩니다. 화면에서 등록한 단어를 포함하여 파일에 없는 단어는 삭제됩니다. 필요한 경우 먼저 다운로드하여 사본을 보관하고, 그 내용을 포함하여 업로드하십시오.
