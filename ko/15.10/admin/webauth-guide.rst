========
웹 인증
========

개요
====

여기서는 웹을 대상으로 한 크롤링에서 웹 인증이 필요한 경우의 설정 방법에 대해 설명합니다.
|Fess| 는 BASIC 인증, DIGEST 인증, NTLM 인증, FORM 인증에 대한 크롤링을 지원합니다.

관리 방법
======

표시 방법
------

아래 그림의 웹 인증 설정 목록 페이지를 열려면 왼쪽 메뉴의 [크롤러 > 웹 인증]을 클릭합니다.

|image0|

편집하려면 설정 이름을 클릭합니다.

설정 생성
--------

웹 인증 설정 페이지를 열려면 신규 생성 버튼을 클릭합니다.

|image1|

설정 항목
------

호스트명
::::::

인증이 필요한 사이트의 호스트 이름을 지정합니다.
생략한 경우 지정한 웹 크롤링 설정에서 임의의 호스트 이름으로 적용됩니다.

.. warning::

   호스트명을 생략하면 크롤링이 링크나 리다이렉트로 따라간 다른 호스트에도 이 사용자 이름과 비밀번호가 전송됩니다.
   자격 증명이 의도하지 않은 호스트로 전송되지 않도록 호스트명을 지정하십시오.

포트
:::::

인증이 필요한 사이트의 포트를 지정합니다.
모든 포트에 적용하려면 포트를 비워 둡니다. ``-1`` 은 지정할 수 없으며, 0 이상의 값만 입력할 수 있습니다.
이 경우 지정한 웹 크롤링 설정에서 임의의 포트로 적용됩니다.

영역
:::::

인증이 필요한 사이트의 영역 이름을 지정합니다.
생략한 경우 지정한 웹 크롤링 설정에서 임의의 영역 이름으로 적용됩니다.
BASIC 인증과 DIGEST 인증에서는 서버가 반환하는 영역(realm) 이름과 대소문자를 구분하여 비교하며, 일치하지 않으면 자격 증명을 전송하지 않습니다.
NTLM 인증의 챌린지에는 영역 이름이 포함되지 않으므로 NTLM 인증에서는 이 항목이 사용되지 않습니다(잘못된 영역 이름을 지정해도 인증됩니다).

스키마
::::::

인증 방법을 선택합니다.
BASIC 인증, DIGEST 인증, NTLM 인증 또는 FORM 인증을 사용할 수 있습니다.

.. note::

   BASIC, DIGEST, NTLM 스키마는 서버가 요구할 수 있는 인증 방식을 제한하지 않습니다.
   |Fess| 는 서버가 요구한 인증 방식으로 자격 증명을 전송합니다.
   예를 들어 DIGEST 인증으로 등록해도 서버가 BASIC 인증만 요구하면 BASIC 인증으로 전송됩니다(HTTP에서는 자격 증명이 사실상 평문으로 전송됩니다).
   BASIC 인증으로 등록했고 서버가 DIGEST 인증을 요구하면 DIGEST 인증으로 응답합니다.
   NTLM 인증과 BASIC 인증 또는 DIGEST 인증은 서로 대체할 수 없습니다.
   서버가 사용하지 않는 인증 방식의 스키마를 선택하면 자격 증명이 전송되지 않으며 해당 사이트의 문서는 색인되지 않습니다.
   서버가 사용하는 인증 방식을 선택하고, 가능하면 HTTPS를 사용하십시오.

사용자명
::::::::

인증 사이트에 로그인하기 위한 사용자 이름을 지정합니다.
도메인이 필요한 NTLM 인증에서는 사용자 이름을 ``도메인\사용자`` 형식으로 쓰지 말고, 도메인을 아래의 파라미터 ``domain`` 으로 지정하십시오.
``도메인\사용자`` 와 같은 값은 분리되지 않고, 문자열 전체가 사용자 이름으로, 도메인은 비워진 채 전송됩니다.

비밀번호
::::::::

인증 사이트에 로그인하기 위한 비밀번호를 지정합니다.

파라미터
:::::::::

인증 사이트에 로그인하는 데 필요한 설정 값이 있는 경우 설정합니다.
NTLM 인증의 경우 workstation과 domain 값을 설정할 수 있습니다.
설정하는 경우 다음과 같이 기술합니다.

::

    workstation=HOGE
    domain=FUGA

``domain``
    인증을 수행할 도메인 이름입니다. 도메인 계정으로 인증하는 경우에 지정합니다.
    생략하면 도메인이 비워진 채 전송되며 도메인 계정의 인증은 실패합니다.
    소문자로 지정해도 대문자로 변환되어 전송됩니다.

``workstation``
    NTLM 메시지에 포함할 워크스테이션 이름입니다.
    생략하면 |Fess| 가 동작하는 호스트의 호스트 이름이 전송됩니다.

웹 설정
::::::::

위의 인증 설정을 적용할 웹 설정 이름을 선택합니다.
웹 크롤링 설정을 미리 등록해 두어야 합니다.

인증에 실패한 경우
------------------

자격 증명이 잘못되었거나 호스트명, 포트, 영역이 대상 사이트와 일치하지 않아 자격 증명이 전송되지 않으면 서버가 401 (Unauthorized)을 반환하며 해당 사이트의 문서는 색인되지 않습니다.
401은 장애 URL로 기록되므로 :doc:`failureurl-guide` 에서 확인하십시오.
장애 URL로 기록하는 HTTP 상태 코드는 ``crawler.failure.url.status.codes`` 로 변경할 수 있습니다( :doc:`../config/crawler-advanced` ).
또한 401이 반환되어도 이미 색인에 있는 문서는 삭제되지 않습니다.

삭제 버튼을 누르면 설정이 삭제됩니다.
