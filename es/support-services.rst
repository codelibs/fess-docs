Soporte comercial
==================

Acerca del Soporte Comercial
============================

Fess es software de código abierto proporcionado bajo la licencia Apache y puede usarse libremente sin costo tanto para uso personal como comercial.

`N2SM, Inc. <https://www.n2sm.net/>`__ proporciona:

- `N2 Search <https://www.n2sm.net/n2search.html>`__: Versión de producto comercial de Fess

- `Soporte de soluciones de búsqueda <https://www.n2sm.net/products/n2search/support.html>`__: Personalización y asistencia en la construcción de Fess y OpenSearch

N2 Search
=========

`N2 Search <https://www.n2sm.net/n2search.html>`__ difiere de Fess en los siguientes puntos:

- Mejora del rendimiento de búsqueda

- Optimización del uso del disco

- Fortalecimiento de la seguridad de las funciones de administración

- Análisis morfológico compatible con nuevas palabras

Servicios de Soporte
====================

Si necesita los siguientes servicios, considere el `Soporte Comercial (Soporte de soluciones de búsqueda) <https://www.n2sm.net/products/n2search/support.html>`__:

- Consultoría de implementación y operación

- Desarrollo de personalizaciones según requisitos individuales (el proyecto Fess responde a requisitos genéricos, pero no a requisitos considerados individuales)

- Manejo de rastreo de grandes volúmenes de documentos (proyectos que involucran más de 500,000 documentos requieren conocimiento suficiente de Fess/OpenSearch)

- Configuración de clustering

- Optimización de resultados de búsqueda para búsqueda empresarial/búsqueda interna corporativa

- Ajuste de servidores Fess/OpenSearch

- Investigación y manejo de archivos que no se indexan (el proyecto Fess no proporciona soporte adicional cuando las bibliotecas dependientes no pueden leer; consulte el soporte comercial si es necesario)

- Construcción de entorno de sistema de búsqueda de texto completo de alta velocidad

- Mantenimiento de versiones específicas (el proyecto Fess solo realiza correcciones a la última versión)

- Capacitación

- Otros servicios

Preguntas Frecuentes
====================

P: ¿Cuál es la diferencia entre la edición de código abierto y la edición comercial?
------------------------------------------------------------------------------------

R: La edición de código abierto (Fess) es gratuita, pero el soporte técnico se basa en la comunidad.
La edición comercial (N2 Search) incluye mejoras en el rendimiento de búsqueda, funciones de seguridad mejoradas y soporte profesional.

P: ¿Puedo probarlo antes de comprarlo?
--------------------------------------

R: Si. El Fess de código abierto se puede descargar y probar inmediatamente desde la `página de descargas <downloads.html>`__.
Para N2 Search, contáctenos a través del formulario de consultas para discutir una prueba.

P: ¿Puedo migrar de Fess a N2 Search?
-------------------------------------

R: Si, la migración es posible. Para procedimientos detallados de migración, contacte al soporte comercial.
Le guiaremos sobre la migración de datos de índices y la transferencia de configuración.

P: ¿Los contratos de soporte son anuales?
-----------------------------------------

R: Los términos de los contratos de soporte son flexibles y pueden adaptarse a sus necesidades.
Para más detalles, contáctenos a través del `formulario de contacto de N2SM <https://www.n2sm.net/contact.html>`__.

P: ¿Se puede usar Fess en entornos de nube?
-------------------------------------------

R: Si, se puede utilizar en las principales plataformas de nube como AWS, Azure y GCP.
Para implementación basada en Docker, consulte la `Guía de instalación con Docker <15.5/install/install-docker.html>`__.
