=============
Documentación
=============

Esta es la documentación actual de |Fess| sobre instalación, búsqueda,
administración, la API y la configuración. Elija a continuación el tema
que necesite.

Si es la primera vez que usa |Fess|, empiece por la :doc:`quick-start`: con Docker, un servidor de búsqueda funciona en unos 5–10 minutos.

.. rst-class:: doc-cards

- :doc:`Instalación <15.9/install/index>`

  Cómo instalar y ejecutar |Fess| en Linux, Windows o Docker, con los requisitos previos, la configuración de seguridad, la actualización y la resolución de problemas.

- :doc:`Búsqueda <15.9/user/index>`

  Cómo escribir consultas de búsqueda en |Fess|: AND, OR y NOT, búsqueda por campo y por etiqueta, ordenación, comodines, rangos, boosting, búsqueda difusa, búsqueda de proximidad y búsqueda geográfica.

- :doc:`Administración <15.9/admin/index>`

  Cómo utilizar cada página de la pantalla de administración de |Fess|: el panel, la configuración del rastreo, los diccionarios, los usuarios y roles, los registros y las copias de seguridad.

- :doc:`API <15.9/api/index>`

  La API de |Fess|: la API de búsqueda, la API de administración para gestionar la configuración, la API de chat con IA, los formatos de petición y respuesta, y la autenticación.

- :doc:`Configuración <15.9/config/index>`

  Configuración organizada por propósito: rastreadores, conectores de Data Store, funciones de búsqueda, seguridad y SSO, el modo de búsqueda LLM/IA, scripting, rendimiento y operación, y administración del sistema.
