====
テーマ
====

概要
====

テーマ機能では、検索画面の外観（HTML / CSS / JavaScript などの静的アセット一式）をまとめたテーマを管理します。テーマは ZIP アーカイブとしてアップロードし、サーバー上のテーマディレクトリ（既定: ``themes`` 、 ``theme.directory.path`` で変更可能）に展開されます。各テーマのルートには、テーマのメタデータを記述した ``theme.yml`` マニフェストを配置します。

検索画面は常にテーマで表示されます。デフォルトテーマを設定していない場合は、 |Fess| に同梱のテーマ ``bootstrap`` が使われます。同梱のテーマは削除も置き換えもできません。変更するには、別の名前で複製します（ :ref:`theme-customize-bundled` を参照）。

.. note::
   JSP ベースのテーマ（ ``fess-theme-*`` の JAR テーマプラグイン）は 15.9 で削除されました。見た目を変えるにはテーマを使います（ :ref:`upgrade-159-static-theme` を参照）。
   本ページの操作を行うには ``admin-theme`` ロール（参照のみの場合は ``admin-theme-view`` ロール）が必要です。

テーマの入手
============

|Fess| プロジェクトが開発しているテーマは、 https://maven.codelibs.org/release/org/codelibs/fess/themes/ 以下に ZIP アーカイブとして公開されています。配置は ``<name>/<version>/<name>-<version>.zip`` で、それぞれに ``.sha1`` チェックサムが並んでいます。

テーマのバージョンは、そのテーマが対象とする |Fess| の系列を表します。 ``15.10.0`` は |Fess| 15.10 用のテーマで、 ``minFessVersion`` も同じことを示します。上限を表すフィールドはありません。公開されたアーカイブは変更されないため、新しい |Fess| で動作しなくなったテーマにあとから上限を追加することはできないからです。その系列向けに公開しないことで、分かった時点で同じことを表せます。

インストールの方法は 3 つあります。

* このページでリポジトリからインストールします。以下の `リポジトリからのインストール`_ の手順を参照してください。
* ``bin/fess-setup install theme <name>`` は、この |Fess| 用に作られたテーマをダウンロードし、公開されているチェックサムと照合してインストールします。 :doc:`../install/fess-setup` を参照してください。
* ZIP をダウンロードし、このページの `テーマのアップロード`_ の手順でアップロードします。

`fess-themes <https://github.com/codelibs/fess-themes>`__ リポジトリのチェックアウトからテーマをパッケージングすることもできます。手元のソースと必ず一致します。 :doc:`../dev/theme-development` を参照してください。

管理方法
======

表示方法
------

登録済みテーマの一覧ページを開くには、左メニューの [システム > テーマ] をクリックします。

テーマ一覧
------

一覧ページには、テーマディレクトリに登録されているテーマが表示されます。各行に表示される項目は以下のとおりです。

.. tabularcolumns:: |p{4cm}|p{8cm}|
.. list-table::

   * - サムネイル
     - テーマディレクトリ内の ``thumbnail.png`` を表示します。存在しない場合は表示されません。
   * - 名前
     - テーマ名（テーマのディレクトリ名）です。クリックすると詳細ページを表示します。
   * - 表示名
     - マニフェストの ``displayName`` です。
   * - バージョン
     - マニフェストの ``version`` です。
   * - デフォルト
     - デフォルトテーマに設定されている場合にチェックが表示されます。
   * - 操作
     - テーマを削除するための削除ボタンが表示されます（デフォルトテーマには表示されません）。

表: テーマ一覧の項目


デフォルトテーマの設定
----------

一覧ページ上部のプルダウンメニューからテーマを選択し、[デフォルトに設定] ボタンをクリックすると、検索画面に適用するデフォルトテーマを設定できます。[（デフォルトなし）] を選択して設定すると、デフォルトテーマの指定を解除し、同梱の ``bootstrap`` テーマに戻ります。設定後はテーマ情報が再読み込みされ、ただちに反映されます。


リポジトリからのインストール
----------------------------

一覧ページでは、テーマリポジトリ（ ``theme.repositories`` 、既定は https://maven.codelibs.org/release/org/codelibs/fess/themes/ ）に公開されているテーマもインストールできます。

* [利用可能なテーマ] には、リポジトリが公開しているテーマがバージョンとともに並びます。行の [インストール] をクリックすると、そのバージョンをインストールします。
* [名前を指定してインストール] では、一覧に出ているかどうかにかかわらず、名前とバージョンを指定してテーマをインストールします。[名前] と [バージョン] を入力して [インストール] をクリックします。

ZIP はリポジトリからダウンロードされ、公開されている ``.sha1`` チェックサムと照合したうえで、アップロードと同じ方法でインストールされます。そのため同じ検査が行われます。使うには、インストール後にデフォルトテーマに設定してください。


テーマのアップロード
----------

[アップロード] ボタンをクリックするとアップロードページが開きます。テーマ ZIP ファイルを選択して [アップロード] ボタンをクリックすると、テーマがインストールされます。

* アップロードできるのは ``.zip`` 形式のアーカイブのみです。
* 圧縮ファイルのサイズ上限は既定で 50 MB（ ``theme.upload.max.size`` ）です。
* ZIP アーカイブのルートには ``theme.yml`` マニフェストが必要です。

すでに同名のテーマが存在する場合は置き換えられます。置き換えられた元のテーマは一定期間（既定 7 日、 ``theme.upload.attic.retention.days`` ）バックアップとして保持されます。

アップロードしたアーカイブがマニフェストの検証に失敗した場合や、展開後のサイズ・エントリ数・圧縮率がサーバーの上限を超えた場合（zip 爆弾対策）はインストールが拒否され、エラーメッセージが表示されます。


theme.yml マニフェスト
----------

テーマのルートには、テーマのメタデータを記述した ``theme.yml`` （YAML 形式）を配置します。指定できるフィールドは以下のとおりです。

.. tabularcolumns:: |p{3cm}|p{2cm}|p{7cm}|
.. list-table::
   :header-rows: 1

   * - フィールド
     - 必須
     - 説明
   * - ``apiVersion``
     - 必須
     - ``fess.codelibs.org/v1`` を指定します。
   * - ``kind``
     - 必須
     - ``StaticTheme`` を指定します。
   * - ``name``
     - 必須
     - テーマ名です。 ``^[a-z0-9][a-z0-9_-]{0,63}$`` のパターンに従う必要があり、テーマのディレクトリ名と一致している必要があります。
   * - ``displayName``
     - 必須
     - 画面に表示する名前です（最大 4096 文字）。
   * - ``version``
     - 必須
     - SemVer 形式のバージョン（例: ``1.0.0`` ）です。
   * - ``author``
     - 任意
     - 作者です。
   * - ``description``
     - 任意
     - 説明です。
   * - ``license``
     - 任意
     - ライセンスです。
   * - ``homepage``
     - 任意
     - ホームページ URL です。
   * - ``minFessVersion``
     - 任意
     - 対応する最小の |Fess| バージョンです。
   * - ``supportedLocales``
     - 任意
     - 対応するロケールです。
   * - ``entry``
     - 任意
     - エントリーポイントとなるファイルです（既定: ``index.html`` ）。
   * - ``spaFallback``
     - 任意
     - 非推奨で、読まれません。15.9 からは検索画面の各パスで常にエントリーポイントのファイルが返ります。

表: theme.yml のフィールド


テーマの削除
------

一覧ページの削除ボタン、または詳細ページの [削除] ボタンからテーマを削除できます。デフォルトテーマに設定されているテーマは削除できません。削除する前にデフォルトテーマの指定を解除してください。削除されたテーマは一定期間（既定 7 日、 ``theme.upload.attic.retention.days`` ）バックアップとして保持されます。


再読み込み
------

テーマディレクトリをサーバー上で直接編集した場合などに、[再読み込み] ボタンをクリックすると、ディスク上のテーマ情報をメモリに再読み込みできます。


テーマ詳細
------

一覧ページでテーマ名をクリックすると、詳細ページが表示されます。詳細ページでは、マニフェストの内容（名前、表示名、バージョン、デフォルトの可否、状態）を確認できます。


.. _theme-settings:

テーマ設定
----------

テーマによっては、管理者が設定値を渡して動作を変えられます。設定は管理画面の [システム > 全般] の「テーマ設定」に ``key=value`` の形式で1行ずつ入力します（ :doc:`general-guide` を参照）。 |Fess| は内容を解釈せず、 ``GET /api/v2/ui/config`` の ``theme_settings`` としてテーマに渡します（ :doc:`../api/api-uiconfig` を参照）。使えるキーと値の意味は、テーマごとに定められています。

値は検索画面を使うすべてのユーザーに見えます。「ログインが必要」が有効でも、ログインしていないユーザーに見えるため、パスワードなどの秘密情報は入力しないでください。

ファイル検索テーマの ``filesearch.roots``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

ファイル検索テーマ（ ``filesearch`` 、バージョン 15.10.6 以降）は、フォルダツリーの最上位に表示するフォルダを ``filesearch.roots`` で指定できます。指定しない場合、ツリーはソース（ホスト）から始まります。 |Fess| 15.10 以降で利用できます。

::

    filesearch.roots=smb://server/share/Documents/|file:/data/docs/

- 値は、URL の接頭辞を ``|`` で区切って並べたものです。項目の前後の空白は無視され、項目の途中の空白は URL の一部になります。
- 接頭辞は、検索結果の ``url`` フィールドに保存されている形で書きます。 ``smb:`` の URL はデコードされた形（ ``smb://server/share/My Docs/`` ）、 ``file:`` の URL はパーセントエンコードされた形（ ``file:/data/My%20Docs/`` ）です。末尾に ``/`` がなければ補われます。
- 指定できるのは最大20件で、URL エンコードした合計サイズにも上限があります（日本語を含むパスでは入る件数が少なくなります）。書いた順に取り込まれ、入りきらない分は無視されるため、重要なものを先に書いてください。1件は500文字までです。URL でない項目、制御文字を含む項目、ほかの項目に含まれる項目も無視されます。
- ツリーの最上位は、指定したフォルダだけになります（名前順）。現在のキーワードや絞り込みの条件でドキュメントがないフォルダは表示されないため、入力を誤ると、そのフォルダが表示されないことで気づけます。
- 指定したフォルダはツリーの起点を変えるだけで、アクセス制御ではありません。検索対象や、ユーザーが見られるドキュメントの範囲は変わりません。見られる範囲を制限するにはロールを使います（ :doc:`../config/security-role` を参照）。

設定プロパティ
======

テーマ機能に関連する主な設定は ``fess_config.properties`` で変更できます。

.. tabularcolumns:: |p{6cm}|p{3cm}|p{5cm}|
.. list-table::
   :header-rows: 1

   * - プロパティ
     - 既定値
     - 説明
   * - ``theme.directory.path``
     - ``themes``
     - テーマを格納するディレクトリです（サーブレットコンテキストからの相対パス、または絶対パス）。
   * - ``theme.upload.max.size``
     - ``52428800``
     - アップロードできる ZIP の最大サイズ（バイト、約 50 MB）です。
   * - ``theme.upload.max.extracted.size``
     - ``209715200``
     - 展開後の最大合計サイズ（バイト、約 200 MB）です。
   * - ``theme.upload.max.entries``
     - ``1000``
     - ZIP に含められる最大エントリ数です。
   * - ``theme.upload.max.compression.ratio``
     - ``100``
     - エントリ単位での最大圧縮率です。
   * - ``theme.upload.zip.ratio.max``
     - ``50``
     - 累積圧縮率の上限です（zip 爆弾対策）。
   * - ``theme.upload.zip.ratio.check.threshold.bytes``
     - ``65536``
     - 累積圧縮率の評価を開始する圧縮バイト数です。
   * - ``theme.upload.attic.retention.days``
     - ``7``
     - 置き換え・削除したテーマのバックアップを保持する日数です。
   * - ``theme.repositories``
     - ``https://maven.codelibs.org/release/org/codelibs/fess/themes/``
     - テーマをインストールするリポジトリの URL（カンマ区切り）です。
