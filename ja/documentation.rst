============
ドキュメント
============

|Fess| の最新バージョンのインストール、検索、管理画面の操作、API、\
各種設定をまとめたドキュメントです。目的の項目を以下から選んでください。

はじめて |Fess| を使う場合は、:doc:`quick-start` から始めてください。Docker なら 5〜10 分ほどで検索サーバーが動きます。

.. rst-class:: doc-cards

- :doc:`インストール <15.9/install/index>`

  Linux、Windows、Docker への |Fess| のインストールと起動の方法を、動作要件、セキュリティ設定、アップグレード、トラブルシューティングとあわせて説明します。

- :doc:`検索 <15.9/user/index>`

  AND・OR・NOT、フィールド検索やラベル検索、並び替え、ワイルドカード、範囲指定、ブースト、あいまい検索、近接検索、位置情報検索など、|Fess| での検索の書き方を説明します。

- :doc:`管理 <15.9/admin/index>`

  ダッシュボードやクロール設定から、辞書、ユーザーとロール、ログ、バックアップまで、|Fess| の管理画面の各ページの操作を説明します。

- :doc:`API <15.9/api/index>`

  検索 API、設定を操作する管理 API、AI チャット API、リクエストとレスポンスの形式、認証方法など、|Fess| の API について説明します。

- :doc:`設定 <15.9/config/index>`

  クローラー、データストアコネクタ、検索機能、セキュリティと SSO、LLM/AI 検索モード、スクリプティング、パフォーマンスと運用、システム管理の設定を、目的別にまとめています。
