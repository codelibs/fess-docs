=============
Documentation
=============

This is the current |Fess| documentation, covering installation, search,
administration, the API, and configuration. Choose the topic you need below.

If you are new to |Fess|, start with the :doc:`quick-start`: with Docker, a search server is running in about 5–10 minutes.

.. rst-class:: doc-cards

- :doc:`Installation <15.9/install/index>`

  How to install and run |Fess| on Linux, Windows, or Docker, with the prerequisites, security settings, upgrading, and troubleshooting.

- :doc:`Search <15.9/user/index>`

  How to write search queries in |Fess|: AND, OR and NOT, field and label search, sorting, wildcards, ranges, boosting, fuzzy search, proximity search, and geo search.

- :doc:`Administration <15.9/admin/index>`

  How to operate every page of the |Fess| administration screen, from the dashboard and crawl settings to dictionaries, users and roles, logs, and backups.

- :doc:`API <15.9/api/index>`

  The |Fess| API: the search API, the admin API for managing settings, the AI chat API, request and response formats, and authentication.

- :doc:`Configuration <15.9/config/index>`

  Settings organized by purpose: crawlers, data store connectors, search features, security and SSO, the LLM/AI search mode, scripting, performance, and system administration.
