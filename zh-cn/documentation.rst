============
文档
============

这是 |Fess| 当前版本的文档，涵盖安装、搜索、管理、API 及各项设置。\
请从下方选择所需内容。

初次使用 |Fess| 时，请从 :doc:`quick-start` 开始。使用 Docker，约 5〜10 分钟即可运行搜索服务器。

.. rst-class:: doc-cards

- :doc:`安装 <15.9/install/index>`

  说明如何在 Linux、Windows 或 Docker 上安装并启动 |Fess|，并涵盖运行要求、安全设置、升级与故障排查。

- :doc:`搜索 <15.9/user/index>`

  说明在 |Fess| 中编写搜索条件的方法，涵盖 AND、OR、NOT、字段搜索与标签搜索、排序、通配符、范围、加权、模糊搜索、邻近搜索和地理搜索。

- :doc:`管理 <15.9/admin/index>`

  说明 |Fess| 管理界面各页面的操作，涵盖仪表板、爬取设置、词典、用户与角色、日志以及备份。

- :doc:`API <15.9/api/index>`

  介绍 |Fess| 的 API，包括搜索 API、用于管理设置的管理 API、AI 聊天 API、请求与响应格式，以及认证方式。

- :doc:`设置 <15.9/config/index>`

  按目的整理的各项配置：爬虫、数据存储连接器、搜索功能、安全与 SSO、LLM/AI 搜索模式、脚本、性能与运维以及系统管理。
