=========
文件认证
=========

概述
====

本节介绍在爬取文件时需要进行文件认证的配置方法。
|Fess| 支持对 FTP 或 Windows 共享文件夹进行认证。

管理方法
======

显示方法
------

要打开下图所示的文件认证设置列表页面，请点击左侧菜单中的 [爬虫 > 文件认证]。

|image0|

点击设置名称可进行编辑。

创建设置
--------

要打开文件认证设置页面，请点击新建按钮。

|image1|

配置项
------

主机名
::::::

指定需要认证的站点的主机名。
请使用与要爬取的 URL 中的主机名相同的名称。对于使用其他名称（例如 IP 地址而不是别名）书写的 URL，不会使用此认证。

端口
::::

指定需要认证的站点的端口。
留空时，列表中显示“任意”。端口留空的含义因协议而异。

* FTP: 用于任意端口的 URL（不含端口的 URL 视为 21 号端口）。
* SAMBA: 仅用于不含端口的 URL（ ``smb://服务器名/共享名/`` ）。不用于像 ``smb://服务器名:445/共享名/`` 这样明确写出端口的 URL。要爬取明确写出端口的 URL 时，请在此处指定相同的端口。

协议
::::::

选择认证方法。
可以使用 FTP 或 SAMBA（Windows 共享文件夹认证）。

用户名
::::::::

指定登录认证站点的用户名。

密码
::::::::

指定登录认证站点的密码。

参数
:::::::::

在需要设置登录认证站点所需的配置值时使用。对于 SAMBA，可以设置 domain 的值。设置时请按如下方式描述。

::

    domain=FUGA

文件爬取设置
:::::::::::::::

指定使用此认证设置的爬取配置。

删除设置
--------

点击列表页面的设置名称，然后点击删除按钮，将显示确认画面。
点击删除按钮将删除该设置。
