=========
爬网信息
=========

概述
====

爬虫的执行结果会被记录，爬网信息可以在此管理界面中查看。

管理方法
======

列表
====

每次执行爬虫时都会记录为爬网信息。
在列表中可以查看已执行爬虫的会话名称和执行时间。
如果要查看爬网信息的详细内容，请点击目标爬网信息。

|image0|

正在运行的爬网
==============

有正在运行的爬网时，列表上方会显示“正在运行的爬网”。每个网站、文件系统或数据存储爬网配置占一行，包含以下项目。

- 爬网配置：爬网配置的名称。
- 已处理文档数：正在运行的爬网到目前为止已处理的文档数。网站和文件系统爬网为访问结果的数量，数据存储爬网为该爬网配置已建立索引的文档数。
- 进度：已处理文档数占上一次完成的爬网的文档数的百分比（%）。爬网完成之前最高为 99%。如果没有上一次完成的爬网（例如首次爬网），则无法计算百分比，此时显示 ``-`` ，仅显示数量。

补充说明：

- 显示的是打开页面时的内容。要查看最新的值，请重新加载页面。
- 已完成或已停止的爬网在下次打开页面时不再显示。如果爬虫在未记录的情况下中断（例如进程被强制终止），则该爬网会在最后一次更新约 30 秒（默认）后消失。已停止或失败的爬网不会改变上一次完成的爬网的文档数；未处理任何文档就完成的爬网也不会替换该数量。
- 进度状态由系统保存在爬网配置的 ``metadata`` 字段中，无法在管理界面或管理 API 中编辑。
- 同样的信息也可以通过管理 API 获取（参见 :doc:`../api/admin/api-admin-crawlinginfo` ）。
